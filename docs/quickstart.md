# 智能座舱实验控制台

Flask + Socket.IO 实现主试控制、驾驶模拟端和平板任务端通信。来自个人座舱研究工具，公开包保留原界面与核心逻辑，默认本机运行。

![主试控制台](../assets/cockpit-operator.jpg)

## 启动

推荐 Python 3.12。在仓库根目录运行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

- 主试端：http://127.0.0.1:18767/operator
- 驾驶模拟端：http://127.0.0.1:18767/subject
- 平板任务端：http://127.0.0.1:18767/tablet

使用 DEMO-001 等虚构编号，主试同步序列后切换培训页面，在平板端完成任务，查看回传事件并下载 CSV。实验模式需用户点击进入以允许全屏/播放。

## 视频与数据

公开包不含真实参与者记录、研究视频或设备数据。完整刺激播放需要在 `videos/LOW/`、`videos/HIGH/` 添加自己有使用权的研究视频；预期文件名见 `templates/subject.html`。没有视频也能查看三端界面、同步序列、培训页和执行平板任务，但不能完成视频实验。

## 公开版本整理

将固定演示密钥改为运行时生成，关闭调试，默认仅监听本机，采用同源 Socket.IO，并修复同步设置被广播两次的问题。原版依赖的 Tailwind 和 Socket.IO 浏览器脚本仍通过公共 CDN 加载，首次运行需要网络。

## 范围与限制

单会话研究工具；内存与浏览器保存会话数据，没有多用户权限、持久化、断线状态恢复与实验隔离。不用于公开网络或正式参与者数据托管。刺激与问卷是否适合具体研究需要独立确认。
